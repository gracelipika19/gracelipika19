## 🚀 Featured Projects

### 1. AI-Based Knowledge Graph Builder for Enterprise Intelligence

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/gracelipika19/AI-Knowledge-Graph-Builder)

An intelligent enterprise knowledge extraction and retrieval system that transforms unstructured and structured data into interconnected knowledge.

- Extracts entities and relationships from emails, PDFs, Excel files, and structured databases.
- Builds knowledge graphs using Neo4j.
- Implements semantic search with FAISS embeddings.
- Combines graph-based retrieval and vector search through a Hybrid RAG architecture.
- Integrates an LLM-powered conversational interface using Streamlit and Groq.

**Tech Stack:** Python, Neo4j, FAISS, RAG, Sentence Transformers, Groq, Streamlit.

### 2. VisionInspectAI – PCB Defect Detection

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/gracelipika19/VisionInspectAI)

An AI-powered visual inspection project designed to identify defects in Printed Circuit Boards (PCBs).

- Implements object detection using YOLO11.
- Detects six PCB defect categories: missing hole, mouse bite, open circuit, short, spur, and spurious copper.
- Explores automated quality inspection and defect analysis.
- Achieved **98.9% mAP@50** on the reported test evaluation.

**Tech Stack:** Python, YOLO11, Computer Vision, Deep Learning, Google Colab.

### 3. FranchiseOpsAI – Agentic AI Operations Copilot

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/gracelipika19/FranchiseOpsAI)

An agentic AI application designed to support multi-outlet franchise operations through intelligent data analysis.

- Uses a LangGraph-based supervisor to coordinate specialized agents.
- Routes business queries to appropriate outlet analytics and sentiment analysis agents.
- Analyzes sales data and customer feedback.
- Provides conversational access to business insights.
- Containerized using Docker.

**Tech Stack:** Python, LangGraph, Agentic AI, Streamlit, SQLite, Docker.

### 4. GenAI Interview Preparation Platform

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat&logo=github)](https://github.com/gracelipika19/genai-interview-prep)

A learning-focused platform designed to help developers prepare for Generative AI interviews and strengthen their understanding of modern AI concepts.

- Focuses on Generative AI concepts and interview preparation.
- Organizes learning resources around important GenAI topics.
- Supports structured technical learning and interview readiness.
- Explores practical concepts related to LLMs and AI application development.

**Focus Areas:** Generative AI, LLMs, AI Engineering, Interview Preparation.

### 5. Edemy – Learning Management System

An online learning platform built using the MERN ecosystem, providing a digital environment for students and instructors.
